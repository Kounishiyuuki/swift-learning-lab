# Swift Learning Lab v0.5

Swiftを「超基礎（Starter）」「言語」「データ/Foundation」「Concurrency/Memory」「開発実務」「SwiftUI」「UIKit」に分離して学ぶ個人用Web教材です。

初めてSwiftを学ぶ場合は Swift Starter から始めてください。値・型・nil・Optional・`{ }`・引数・property / method といった用語が未知の段階から読めるトラックです。

## 学習アイテムの内訳

| 種類 | 数 | 内容 |
|---|---|---|
| 知識問題 | 252 | 読んで理解したことを4択で確認する。全問に詳細解説つき |
| 実装練習 | 300 | 手を動かして「自分で書ける」状態にする。10形式・3段階ヒントつき |
| **総学習アイテム** | **552** | |

知識問題と実装練習は別モード・別進捗です。既存の252問のID・選択肢・正解・詳細解説・localStorage進捗は v0.4.0 から変更していません。

## v0.5.0
- 実装練習モードを追加（300問）
- 10種類の問題形式に対応
- 全300問に3段階ヒントと、なぜその解答で動くのかまで踏み込んだ解説を収録
- 「実装力」ダッシュボード（スキル別の到達度）を追加
- 復習リストと、ヒントなしでの解き直しに対応
- 次に解く問題の推薦と、6軸の絞り込み・検索を追加
- 知識問題の252問・進捗データは変更なし（旧localStorageもそのまま使えます）

### 実装練習の10形式

| 形式 | 日本語表示 | やること |
|---|---|---|
| `reorder` | 並べ替え | すべてのブロックを正しい実行順に並べる |
| `fillBlank` | 穴埋め | コード中の空欄に入るものを選ぶ |
| `chooseBlocks` | ブロック選択 | 必要なブロックだけを選んで組み立てる（不要な候補が混ざる） |
| `bugHunt` | バグ発見 | 問題のある1行を特定する |
| `repair` | 修正 | 壊れたコードに対する正しい修正を選ぶ |
| `trace` | 実行追跡 | 実行するとどうなるかを追う |
| `matching` | 対応づけ | 用語と役割、データと保存先などを1対1で結ぶ |
| `buildFunction` | 関数組み立て | 関数1つ分を、不要な候補を捨てながら組み立てる |
| `shortCode` | 記述 | 1行を自分で書く |
| `testReasoning` | テスト読解 | テスト結果から実装の不足を読み取る |

### ヒントと採点

ヒントは1問につき必ず3段階で、見た段階に応じてスコアが下がります。

| 解き方 | スコア |
|---|---|
| ヒントなしで正解 | 100 |
| ヒント1まで見て正解 | 85 |
| ヒント2まで見て正解 | 65（ここまでを「習得」とみなす） |
| ヒント3まで見て正解 | 45 |
| 解答を表示 | 0（この回はスコアに数えない） |

過去の最高スコアは `bestScore` として残り、あとからヒントを多く使って解き直しても下がりません。

### 復習リスト

次のいずれかに当てはまると、その問題は復習リストに入ります。

- 不正解だった
- 解答を表示した
- ヒントを3つ使った（習得の閾値65に届かなかった）

ヒントなし、またはヒント2までで解き直すと復習リストから外れます。

### 実装力ダッシュボード

スキルタグごとに「解いた数 / 習得率 / 要復習 / ヒントなし正解率」を集計して表示します。集計対象は
文法・記法、制御フロー、関数、Optional、コレクション、型・構造体・クラス、プロトコル・ジェネリクス、
エラー処理、デバッグ、テスト、データ / Foundation、並行処理、メモリ管理、SwiftUI、UIKit、設計・開発フロー の16スキルです。

これは **練習の進み具合の目安であり、開発力を科学的・正確に測るスコアではありません**。
「どのスキルの練習が手薄か」を見るためのものとして扱ってください。

### v0.5.0 の制約（バックエンド・コンパイラなし）

- サーバもバックエンドもありません。`index.html` を開くだけで完全にオフラインで動きます。
- **Swiftコンパイラは使いません。** `shortCode` の判定は、あらかじめ用意した想定解との文字列一致
  （前後の空白・インデント・改行の違いのみ無視）です。意味的に正しい別の書き方は、想定解に
  登録されていなければ不正解になります。この制約は問題画面にも明記しています。
- 進捗はこの端末の localStorage にのみ保存されます。端末間では同期されません。

## 編集

教材データの編集元は `source/content.json`（知識問題）と `source/practice.json`（実装練習）だけです。
`index.html` への埋め込みと `source/<track>.txt` / `source/practice.txt` の生成は build が行うため、
生成物を直接編集しないでください。

```bash
python3 tools/build.py
```

`build.py` は埋め込み前に必ず `tools/validate_practice.py` を実行するため、壊れた practice.json が
`index.html` に入ることはありません。生成は冪等で、2回実行しても差分は出ません。

### 検証ツール（すべて外部パッケージ不要）

```bash
python3 tools/validate_practice.py     # 300問の構造検証（件数・型・ヒント3つ・解説・参照整合性）
python3 tools/verify_examples.py       # 全問の関連例Swiftを実際にコンパイル・実行して出力を照合
node tools/test_engine.mjs             # 練習エンジンの回帰テスト（10形式の描画・採点・保存・復習）
```

`verify_examples.py` は `swift` コマンドを使います。UIKit / SwiftUI を import する例は macOS 上で
実行できないため対象外として数えます（UIKitの動作をコンパイルで検証しているわけではありません）。
